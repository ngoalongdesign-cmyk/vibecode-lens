# VibeCode Lens

https://github.com/ngoalongdesign-cmyk/vibecode-lens/raw/main/demo/demo-en.mp4

**For AI builders who can see the UI bug but don't know what to call it.**

VibeCode Lens is a free Chrome extension. Hover over any part of a web UI — it tells you what it is, suggests what you want to fix, and generates a prompt you can paste straight into Claude, Cursor, Lovable, Bolt, or any AI you're using.

---

## Why it exists

Most people building with AI aren't developers. When they spot something wrong in the UI, they tell the AI:

> "Fix this part to look better."  
> "That section looks off."

The AI gets the gist — but guesses wrong. You end up re-explaining three times, wasting tokens, and getting more frustrated each iteration.

Lens solves the exact moment where that breaks down: you see the problem with your eyes, Lens helps you say it in a way AI understands precisely.

---

## Features

- **24 UI element types** — navbar, sidebar, card, button, chat input, search bar, pricing table, hero, modal, and more
- **Fix intent suggestions** — pick "cleaner", "more prominent", "simpler"… and get a prompt instantly
- **Auto-generated prompts** — built from the element type and the intent you pick
- **Override if it guesses wrong** — type picker inside the panel, and Lens remembers your choice for that spot on that page
- **Vietnamese and English** — toggle inside the panel
- **Zone lock** — click to pin the selected element while you work
- **Keyboard shortcuts** — no mouse needed once you know the flow

---

## Install

Not on the Chrome Web Store yet. Install via Developer Mode:

1. [**Download the `.zip`**](https://vibecode.maralabs.vn/vibecode-lens-extension-v0.3.0.zip) and unzip it
2. Open `chrome://extensions`
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** → select the unzipped folder
5. Press `Alt + Shift + L` on any page to activate Lens

---

## Shortcuts

| Key | Action |
|-----|--------|
| `Alt + Shift + L` | Toggle Lens on / off |
| `Esc` | Close panel |
| `Click` | Lock the hovered zone |
| `C` | Copy prompt |
